Plain-language policy

Privacy

Context Check is built so we do not receive your source code, comparisons, settings, or dismissed suggestions.

What stays on your device

The VS Code extension reads permitted files in the local workspace to build a local vocabulary and compares newly introduced editor text there. It excludes environment files, secret directories, and PEM files by default. The Chromium companion reads visible GitHub pull request, commit, and compare pages only when those pages are open. Matching happens inside the relevant extension. Disabled path patterns, dismissed token pairs, and page results are stored in local extension storage.

What we collect

Nothing from the extension. There are no user accounts, analytics SDKs, advertising cookies, crash reporters, telemetry endpoints, or remote model calls. The hosted website may be subject to ordinary short-lived infrastructure access logs maintained by the deployment provider for security and reliability; the product does not read or profile them.

Permissions

VS Code workspace access lets the local extension read permitted workspace files and show local diagnostics. github.com access lets the optional Chromium companion inspect visible diff text and place local proof notes beside added lines. Storage saves browser-companion settings and dismissals. Context Check does not request access to other websites.

Delete your data

Uninstall the VS Code extension to remove its saved dismissals. In the Chromium companion, choose “Restore dismissed pairs” or remove the extension to clear its local storage.

Contact and changes

Questions can be opened in the public project issue tracker. Material changes will be dated here and shipped with a new extension version.
