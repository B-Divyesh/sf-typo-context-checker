## Controls and terminology

- Product: “Context Check”
- Existing source terms: “repository vocabulary” / field label “Existing project words”
- New source terms: “newly introduced tokens” / field label “New change”
- A flagged pair: “possible confusion”
- Corrective UI: “Quick Fix”
- Exclusion UI: “sensitive path”
- Primary actions: “Download for VS Code”, “Try it with sample data”, “Check these lines”
