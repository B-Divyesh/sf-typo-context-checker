## Plain-words review

- Every visitor-facing sentence is 22 words or fewer.
- No banned marketing words appear.
- Section labels and headings name their content directly: “Sample checker,” “Compare sample code tokens,” “How it works,” “Check new code tokens as you edit,” “Privacy,” and “Questions about Context Check.”
- Removed metaphor or mood labels: “Developer proof desk,” “The proof sheet,” “See what ‘almost’ looks like,” “A quiet check, right where the change begins,” “No cloud in the loop,” and “Questions before you pin it.”

## Controls and terminology

- Product: “Context Check”
- Existing source terms: “repository vocabulary” / field label “Existing project words”
- New source terms: “newly introduced tokens” / field label “New change”
- A flagged pair: “possible confusion”
- Corrective UI: “Quick Fix”
- Exclusion UI: “sensitive path”
- Primary actions: “Try it with sample data”, “Download for VS Code”, “Check these lines”
