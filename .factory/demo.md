# Demo sandbox

- URL: `https://typo-context-checker.sociobot.in/demo/` (local: `http://127.0.0.1:4173/demo/`).
- Entry: choose **Try it with sample data** on the first screen.
- Sample: trusted `database_url`, `paymentRetryCount`, deployment command, and session token vocabulary; the changed lines contain two realistic transpositions.
- Reset: choose **Reset demo**. This reloads the bundled sample.
- Storage: the demo has no storage namespace because it never reads or writes browser storage. All input and results exist only in the page until it closes.
- Exit: choose **Start for real** to return to the install and local-check page.
